# CodeAtlas 里程碑 3：Roslyn 精确语义 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 对 C# 用 Roslyn 的语义模型产出精确的符号与边（重载、泛型、扩展方法、接口方法到实现方法、DI 注册、按类型分发），覆盖掉 tree-sitter 的启发式边；在 ccs-backend 上消除 `GetAsync` 这类多候选噪声和"同文件同名误判"。

**Architecture:** 独立进程 `codeatlas-roslyn.exe`（`CodeAtlas.Roslyn.Worker`）用 MSBuildWorkspace 打开 .sln，向 stdout 流式输出 JSON Lines（file / symbol / edge / di / progress / error / done）。分析逻辑在类库 `CodeAtlas.Indexing.Roslyn`（`RoslynAnalyzer`），可在测试里直接调用不经进程。父进程（CLI `index` 与服务）用 `RoslynRunner` 拉起 worker、逐行消费，`RoslynApplier`（Core）按 spec 3.4 的覆盖规则写库：每个 .cs 文件先删 tree-sitter 的 calls / references / inherits / implements / dispatches 边，保留 contains / imports，符号按 (file, start_line, start_col, kind) 合并并升级为 roslyn；边在全部符号入库后按限定名统一挂接；最后重挂悬空边。

**Tech Stack:** Microsoft.CodeAnalysis.CSharp.Workspaces 5.9.0、Microsoft.CodeAnalysis.Workspaces.MSBuild 5.9.0、Microsoft.Build.Locator 1.11.2；worker 为 framework-dependent exe，与 codeatlas.exe 一起发布到 dist/ 与扩展的 server/。

**Spec:** `2026-10-13-codeatlas-design.md` 第 3.4、4.4、4.5、4.7 节与里程碑 3 / 3b；性能目标 8.2（Roslyn 全量 15 分钟内、峰值 8GB 以下）。

## Global Constraints

- Roslyn 产出的方法限定名带参数类型：`Ns.Type.Method(int, string)`；类型/属性/字段不带。重载因此可区分。
- 只索引仓库内源码的符号；引用的程序集成员记为 `external:<显示名>`。
- Roslyn 边 confidence 1.0；`SymbolInfo.CandidateSymbols`（重载歧义）每个 0.8。
- 多目标框架的项目（同一 csproj 出现多次）只取第一个 TFM。
- Worker 的 stdout 只放 JSON Lines；日志走 stderr。父进程 5 秒没读到任何行不算失败（打开解决方案可能要一两分钟），但 10 分钟没有任何进度行视为挂死并终止。
- 索引版本升到 3：schema 新增 `files.roslyn_at`，用于 health 报告 Roslyn 覆盖范围。
- 本计划不做 Roslyn 增量（spec 3.5）；.cs 文件被 tree-sitter 增量重建后，其边回退为启发式，health 报告 `roslynStaleFiles` 数量。

## Review Focus

1. **解决方案里有加载失败的项目**（缺 SDK、缺包）：跳过并上报，不中断。→ Worker 测试用一个故意坏掉的 csproj。
2. **partial class 跨文件**：同一类型在两个文件里声明，符号合并不能把另一半当成新类型。→ Applier 测试。
3. **重载**：`Find(int)` 与 `Find(string)` 必须是两个符号、调用边各自精确。→ Analyzer 测试。
4. **扩展方法与泛型方法**：`items.ToList()` 解析到 `System.Linq.Enumerable.ToList<T>` 外部符号，不再是仓库里的同名方法。→ Analyzer 测试。
5. **Roslyn 跑完后 UI 的分发链不能倒退**：Roslyn 必须自己产出 handles / dispatch / conduit，否则覆盖掉 tree-sitter 的边后链条消失。→ Analyzer 测试 + ccs-backend 验收。
