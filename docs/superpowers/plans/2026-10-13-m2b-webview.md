# CodeAtlas 里程碑 2b：面板页面 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个可在普通浏览器和 VS Code Webview 里运行的邻域图页面：搜索、焦点、展开、多候选折叠、面包屑、跳转消息。

**Architecture:** `extension/` 是一个 npm 包（2c 的扩展代码也放这里）。`webview/graphState.ts` 是无依赖的纯状态机，所有交互先改状态再渲染；`webview/renderer.ts` 只把状态翻译成 Cytoscape 元素并跑 ELK 布局；`webview/api.ts` 封装 2a 的接口；`webview/main.ts` 组装 UI。浏览器模式用 `?api=http://127.0.0.1:PORT` 指定服务；Webview 模式等扩展发 `init`。

**Tech Stack:** TypeScript 5、esbuild 0.28、cytoscape 3.34、elkjs 0.12、cytoscape-elk 2.3、vitest 5。

**Spec:** `docs/superpowers/specs/2026-10-13-vscode-extension-design.md` 第 3 节、里程碑 2b。

## Global Constraints

- 页面不依赖 VS Code API 才能运行；`acquireVsCodeApi` 不存在时所有消息打到 console。
- 只允许的运行时依赖：cytoscape、elkjs、cytoscape-elk。开发依赖：typescript、esbuild、vitest、@types/vscode（2c 用）。
- 状态机不 import 任何 DOM 或 cytoscape 类型。
- 颜色全部用 `--vscode-*` 变量并带浏览器回退值。
- 展开阈值 30；多候选判定依据服务端 `ambiguousGroup` 字段，不自己按 confidence 猜。
- 图的方向遵循 spec：出边目标在左、入边来源在右（ELK `direction: LEFT`）。

## Review Focus

1. **同一个符号从两个方向都能到达**（A 调 B，B 也调 A）：节点不能重复，两条边都要在。→ `GraphState` 测试 `expand_bidirectionalEdges_singleNode`。
2. **胶囊里只剩一个成员时**：展开那一个后胶囊必须消失。→ `expandAmbiguous_removesEmptyCapsule`。
3. **面包屑回退后再展开**：历史分叉时丢弃前方历史。→ `goBack_thenExpand_truncatesForwardHistory`。
4. **悬空边**：`other = null` 的边要画成灰色占位节点而不是崩。→ `applyNeighbors_danglingEdge_makesPlaceholderNode`。
5. **隐藏焦点**：不允许；隐藏其他节点后其边一起消失。→ `hide_focusIsNoop_otherRemovesEdges`。
